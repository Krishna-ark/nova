# NOVA

NOVA is a permission-controlled AI agent operating layer for Windows.

## Current Phase

Phase 1 — application scaffolding.

Phase 1 intentionally does not include:
- AI/LLM integration
- Voice
- Browser automation
- Android/device agents
- Bluetooth automation

These capabilities will be introduced in later milestones.

## Development

Python 3.12 is required.

The project uses a Python virtual environment located at `.venv`.

## Status

Early development.
